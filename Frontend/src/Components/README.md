## 🧩 Components Folder

This folder contains all the reusable and page-specific React components used across the frontend of the Loginfy-MERN project.

### 🔹 List of Components

- **CheckLogin.jsx** – Verifies if the user is logged in.
- **ErrorMessage.jsx** – Displays error messages across the app.
- **FlashMessage.jsx** – Shows temporary flash alerts like success or failure messages.
- **Footer.jsx** – App footer visible on all pages.
- **LoginForm.jsx** – Handles the login form UI and logic.
- **Logout.jsx** – Manages logout functionality.
- **Navbar.jsx** – Responsive navigation bar used throughout the app.
- **Profile.jsx** – Displays the user's profile information.
- **SignupForm.jsx** – Handles the signup form UI and file upload logic.

> All components follow modular design principles and integrate seamlessly with routing, context, and API communication.
